Phase 1 · Needs: all · Implements: —

Bring the feature map in line with what this spec built, so the next planning session finds
current docs. Standard: the **feature-map** skill.

## Decisions

- Update the docs of the touched features from the tasks' notes and deviations in the prompt
  plus `git log --stat` (read-only git only; never run git commands that change state).
- Add this spec to `specs:` of every touched feature doc.

  `run/accounts` ("Multiple Claude accounts": global config, priority and fallback, `--burn`,
  `--account`, `specrun accounts`), depending on `setup/config` and `run/limits`.
